# 群星科研台 v0.2.3

SillyTavern 前端扩展。内置《群星系统》V4.0 科技图，包含 761 个节点、信息时代起步图、ME 的 48 项科技、巨构专项、文明飞升路线和飞升天赋。

## 本地安装

1. 解压 ZIP，将整个 `stellaris-tech-tree` 文件夹放到 SillyTavern 的 `data/default-user/extensions/`。多人安装时，用自己的用户目录名替换 `default-user`。如果酒馆配置了自定义数据目录，从那个目录开始找。
2. 确认 `data/default-user/extensions/stellaris-tech-tree/manifest.json` 存在，刷新酒馆页面。
3. 点击聊天输入框左侧的「✧」，或者在扩展菜单选择「群星科研台」。

## 使用

- 搜索「星门建造」或 `gateway_construction`，查看上游路线、任选组和附加条件。使用鼠标滚轮或双指缩放，也可用图面右上角的缩放按钮。
- 点「标记已掌握」或「撤销登记」手动记录。可直接登记剧情中已经获得的科技，前置与条件仍按档案显示。星门建造的登记会让图上的 L 星门里程碑显示为已达成。
- 循环科技每次点击「登记完成一轮」会增加一次。累计至少一轮时，节点显示为红色，详情与填入输入框的草稿都会标明当前已循环几次。「撤回一轮」会减去一次，旧档案里已点亮的循环科技按一轮计。
- 点「填入输入框」时，科研台核对科技前置，生成立项指令或准备清单。草稿保留 ME 的正式项目编号，并追加到现有输入末尾，可编辑后自行发送。科技进度由面板中的登记按钮更新。
- 立项核对使用科技依赖、起研条件和专项获取条件。场址、验收和选配要求可在科技详情里查看，按实际建设或部署方案核对。
- 勾选节点卡左上角的方框，底部会列出已选节点。切换分类和搜索时可继续勾选。点击底部「填入已选」会生成一份草稿。各项目均可立项时，在末尾统一写明「这些项目所有前置均已满足。」需要筹备时，各项目分别列出缺项，共享的前期课题只展开一次。可以逐项移除或清空列表，切换会话也会清空本次选择。
- 点击「批量掌握」可一次登记选中的科技及可独立登记的里程碑。进度写入当前会话的当前文明档案，已登记的节点会自动跳过。
- 点「档案」可以新建、复制、重命名、导出和导入各条世界线的进度。导入会在当前会话新建一份档案。
- 在「档案」里选择「文明类型」，科技图、搜索、前置路线和飞升档案会按当前文明筛选。新档案和旧版档案默认使用常规文明。类型随档案保存、复制和导出，切换类型后仍可恢复先前登记的进度。
- 科技点亮、条件确认、飞升阶段和文明档案随当前会话保存。同一个角色的新会话从空白档案开始，切回原会话即可恢复原进度。已有 v0.1.0 进度时，可在目标会话打开「档案」，点击「复制旧版全局档案到此会话」。
- 在「飞升之路」可手动记录入口、文明转型和终局进度，也可在「飞升天赋」下登记已采纳的天赋。
- 「灵能存储」〔ME-38〕是 ME 末端支线，前置为「离线数据柜与容灾」〔ME-29〕和「灵能理论」。

## 舰船设计器

- 从科技分类栏右侧进入「舰船设计器」。点击顶部舰级名称可选择舰种和命名。点击蓝图上的波纹点查看设备分类和已装设备，再点击设备分类展开加装列表。窄屏的设备面板出现在绘图区下方。
- 舰体提供基础负载和散热上限。供能设备增加负载上限并占用散热，其他装备按规格和数量消耗负载。设备允许按额度叠装，专用设备保留舰体相容条件。
- 点击任意系统波纹点，打开「自定义设备」并点「新建设备」，填写名称、装配数值和原创设定。模板随插件跨会话保存，可以在同一系统加装到其他舰型。
- 「保存并服役」把设计保存到酒馆账户的设计库，同时登记到本会话的知识书。蓝灯「当前服役舰船列表」显示舰种和舰级，绿灯舰级档案按舰级名触发。
- 舰型保存时会保留已装自定义设备的完整设定。从设计库服役时，舰级和原创设备分别写入当前会话的绿灯条目，按舰级名和设备名称各自触发。多艘在役舰共用同一版本的设备时，该设备只登记一次。改动设备模板后，重新加装即可采用更新过的设定。
- 新会话打开后自动建立自己的舰队知识书。若会话已绑定知识书，舰队档案与原知识书共同生效。可在「设计库」中让已保存的设计服役或退役，退役保留跨会话设计。更新设计时，其他会话仍保留先前部署的配置。
- 方舟等舰种按科研台的当前文明类型显示。舰体额度定义在 `ship-model.mjs`，装备数据来自世界书 V4.0。舰装目录可用 `python3 tools/build-ship-data.py /path/to/worldbook.json` 重新生成。

## 更新科技数据

用 Python 3.9 或以上版本，在扩展目录运行：

```sh
python3 tools/build-tech-data.py /path/to/Stellaris_System_V4.0_Tech_Tree_Overview.json
```

脚本读取世界书的带标签科技表和档案，重新生成 `data/tech-tree.json`。保留科技 ID 可以让旧进度继续对应。图形组件 Cytoscape.js 3.33.1 随包提供，其许可文件位于 `vendor/`。
